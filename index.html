GAA

A small directory of every known graph site and measurement database, rebuilt daily.

The index

db-site-index.json

Merged from GraphAggregator's aggregate-index.json and squig.link's squigsites.json. It carries the site and database directory only — no device corpus — so it stays a few kilobytes rather than a few hundred.

Using it

const res = await fetch('https://potatosalad775.github.io/GAA/db-site-index.json');
const { sites, dbs } = await res.json();
